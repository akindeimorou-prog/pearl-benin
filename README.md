robe-selene.svg, adire-nuit.svg, boubou-oria.svg, kente-prestige.svg,

## Publication
GitHub Pages doit utiliser :
- Branch : `main`
- Folder : `/ (root)`

Après un commit, attendre le déploiement puis faire `Ctrl + F5`.
