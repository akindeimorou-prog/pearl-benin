# PEARL V2
Site vitrine/e-commerce statique pour GitHub Pages.

## Installation
1. Envoyer tous les fichiers dans un dépôt GitHub.
2. GitHub > Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main / root.
5. Remplacer dans `js/app.js`:
   - `SITE.whatsapp`
   - `SITE.instagram`
6. Remplacer les images dans `images/`.

## Produits
Les 10 produits fictifs sont dans `js/products.js`.
